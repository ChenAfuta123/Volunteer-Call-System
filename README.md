# Volunteer Call Management System

A desktop application for managing volunteers and service calls, developed as part of a .NET project.

## Features

* Volunteer management and status tracking
* Viewing and selecting available calls
* Assigning calls to volunteers
* Managing ongoing call treatments
* Completing or cancelling treatments
* Viewing volunteer call history
* Real-time updates using the Observer pattern

## Technologies

* C#
* .NET
* WPF
* XAML
* Object-Oriented Programming
* Layered Architecture
* Observer Design Pattern
* Unit Testing

## Architecture

The project is organized into several layers:

* **PL** – WPF presentation layer and user interface
* **BL** – Business logic and validation
* **BO** – Business objects
* **DO** – Data objects and data access
